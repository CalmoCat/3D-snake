# Neon Runner — 3D Snake

Игра переработана из прототипа в самостоятельный аркадный забег: змейка движется по неоновой арене, собирает машины и усилители, растёт, набивает комбо и переживает столкновения без перезагрузки сцены.

## Что изменилось

- **Полный runtime-прототип без ассетов:** `RuntimeGameBootstrap` создаёт арену, камеру, свет, игрока, трафик и HUD. Исходная сцена теперь действительно есть: `My project/Assets/Scenes/DemoScene.unity`.
- **Нормальный игровой цикл:** очки, уровни, комбо, три жизни, game over, пауза (`P`/`Esc`), рестарт и продолжение после удара.
- **Новые усилители:** рост, щит, магнит, ярость с двойными очками и замедление времени. Активные эффекты отображаются в HUD.
- **Исправлена змейка:** ограниченная история движения, корректное добавление/обрезка хвоста, безопасный респавн, столкновение с собственным телом и отсутствие скачков после потери жизни.
- **Трафик:** безопасный спавн по кольцевому маршруту, процедурные машины, очистка уничтоженных объектов, регулировка плотности и скорости по сложности.
- **Управление:** `A/D` или `←/→` — поворот, `Space`/`Shift` — ускорение, `P`/`Esc` — пауза.
- **Настройки:** скорость, поворот и плотность машин сохраняются через `PlayerPrefs`; слайдеры больше не отключаются сами и не конфликтуют с обработчиками ввода.
- **Графика:** процедурная неоновая арена, сетка-дорожка, цветные машины и бонусы, туман, подсветка, плавная камера и HUD в едином стиле.
- **Совместимость:** старые `MainMenu`, `LoseHandler`, `SegmentCollisionHandler`, префабы машин и ссылки на TextMeshPro сохранены — обновлённые скрипты можно подключать к существующей сцене.

## Запуск в Unity

1. Открыть папку `My project` в **Unity 6000.3.8f1**.
2. Открыть сцену `Assets/Scenes/DemoScene.unity`.
3. Нажать **Play**. Сцена не требует префабов или ручной настройки ссылок.
4. Для пользовательской сцены добавить на пустой объект `RuntimeGameBootstrap`; при необходимости снять `generateOnStart` и подключить свои объекты вручную.

Старый Windows-билд в `Змейка 0.8/` оставлен как исходный артефакт. Он не может содержать новые скрипты, поэтому после изменений билд нужно собрать из Unity заново.
